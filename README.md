# Sdl2 Tutorials in c

This **repo** is a compilation of tutorials made with c for learning sdl2
It includes projects also made with sdl2 and pure c.

SDL2 stands for simple direct media layer and can be used to make all kinds of multimedia apps and games.
c language is very low level and allows for direct memory manipulations and other optimisations.
