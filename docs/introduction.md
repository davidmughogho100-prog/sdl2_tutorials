# Simple Direct Media Layer

**SDL2** is a cross platform library that allows for creation of games and multimedia
applications. Examples of games made with sdl2 include:
1. Portal
2. unkwon

**Apps** made with sdl2 include but not limited to:
1. cava
2. corange game engine

In this guide i will walk you through working with sdl2 from making simple games and even
Complex game mechanics using just **sdl2**.
